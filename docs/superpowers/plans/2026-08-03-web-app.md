# Web App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A professional, production-ready web app at `apps/web` — the merged information architecture of both Lovable prototypes, rebuilt in the new clean/minimal/pastel design system, off Lovable's proprietary packages, wired to the Lumen API.

**Architecture:** Plain TanStack Start + Vite + Tailwind v4, file-based routing, TanStack Query against a typed API client. Server routes act as a BFF: the browser holds only an `HttpOnly` session cookie and never sees a service token. Every screen renders in `mock` mode until its endpoint exists, so the app is demoable at every commit.

**Tech Stack:** React 19, TypeScript 5.7, TanStack Start / Router / Query, Tailwind CSS v4, lucide-react, Vitest + Testing Library, Playwright, npm (Node 24).

**Prerequisites:** `2026-08-03-saas-foundations.md` through Task 7. Tasks 6–9 of this plan additionally need `2026-08-03-agent-layer.md` through Task 7.

**Design contract:** `docs/architecture/design-system.md` is normative. Read it before writing any component. The token source is `apps/web/src/styles.css`.

## Global Constraints

- **No hex colours in components.** Every colour is a Tailwind token backed by a CSS variable (`bg-surface`, `text-ai`, `border-border`, `bg-primary-tint`). A literal `#3B82F6` or `#F59E0B` anywhere under `src/components` is a defect — the prototypes were full of them and none may survive.
- Text and solid fills use the `ink` stop only (`text-primary`, `bg-primary`). Never `text-primary-soft`.
- Blue = the user can act. Violet (`ai`) = the agent acted. Mint (`success`) = a human approved it. Never substitute.
- Every top bar is `h-14` (56px). Panel separation is `border` — never shadow.
- All numbers are `font-mono num-tabular`.
- Both themes and `prefers-reduced-motion` supported from the first commit.
- Every interactive element is keyboard reachable and has an accessible name. Icon-only buttons need `aria-label`.
- Loading states are `.skeleton`, never a spinner for content.
- Package manager is **npm**. Run commands from `apps/web` unless stated.

```tsx
  head: () => ({
    meta: [
      { charSet: "utf-8" },

function RootShell({ children }: { children: React.ReactNode }) {
  const queryClient = new QueryClient({
    defaultOptions: { queries: { staleTime: 30_000, retry: 1 } },
```

Create `apps/web/tests/unit/no-hex-colors.test.ts` — this is the guard that keeps the prototype's hardcoded palette from coming back:

```ts
import { readdirSync, readFileSync, statSync } from "node:fs";
import { join } from "node:path";
import { describe, expect, it } from "vitest";

function walk(dir: string, out: string[] = []): string[] {
  for (const entry of readdirSync(dir)) {
    const full = join(dir, entry);
    if (statSync(full).isDirectory()) walk(full, out);
    else if (/\.tsx?$/.test(entry)) out.push(full);
  }
  return out;
}

describe("design tokens", () => {
  it("no component hardcodes a hex colour", () => {
    const offenders: string[] = [];
    for (const file of walk("src/components")) {
      const text = readFileSync(file, "utf8");
      const matches = text.match(/#[0-9a-fA-F]{3,8}\b/g);
      if (matches) offenders.push(`${file}: ${matches.join(", ")}`);
    }
    expect(offenders).toEqual([]);
  });
});
```

```ts
const counter = new Intl.NumberFormat("en-US");

export function formatCount(value: number): string {
  return counter.format(value);
}

export function formatCompact(value: number): string {
  return new Intl.NumberFormat("en-US", { notation: "compact", maximumFractionDigits: 1 })
    .format(value)
    .toUpperCase();
}

export function formatPercent(ratio: number, digits = 1): string {
  return `${(ratio * 100).toFixed(digits)}%`;
}

export function formatDuration(seconds: number): string {
  if (seconds < 1) return `${Math.round(seconds * 1000)}ms`;
  if (seconds < 60) return `${seconds.toFixed(1)}s`;
  const m = Math.floor(seconds / 60);
  return `${m}m ${Math.round(seconds - m * 60)}s`;
}

export function formatBytes(bytes: number): string {
  const units = ["B", "KB", "MB", "GB", "TB"];
  let value = bytes;
  let unit = 0;
  while (value >= 1024 && unit < units.length - 1) {
    value /= 1024;
    unit += 1;
  }
  return `${value.toFixed(value < 10 && unit > 0 ? 1 : 0)}${units[unit]}`;
}
```

Create `apps/web/src/lib/theme.ts`:

```ts
import { useCallback, useEffect, useState } from "react";

export type Theme = "light" | "dark";
const KEY = "lumen-theme";

export function useTheme() {
  const [theme, setTheme] = useState<Theme>("light");

  useEffect(() => {
    setTheme(document.documentElement.classList.contains("dark") ? "dark" : "light");
  }, []);

  const toggle = useCallback(() => {
    setTheme((current) => {
      const next: Theme = current === "dark" ? "light" : "dark";
      document.documentElement.classList.toggle("dark", next === "dark");
      try {
        localStorage.setItem(KEY, next);
      } catch {
        /* storage unavailable — the class still applies for this session */
      }
      return next;
    });
  }, []);

  return { theme, toggle };
}
```

```tsx
const VARIANTS: Record<Variant, string> = {
  primary: "bg-primary text-primary-foreground hover:brightness-110 shadow-xs",
  secondary: "bg-surface text-foreground border border-border hover:bg-surface-2",
  ghost: "text-muted-foreground hover:bg-surface-2 hover:text-foreground",
  danger: "bg-destructive text-destructive-foreground hover:brightness-110",
};

const SIZES: Record<Size, string> = {
  sm: "h-7 px-2.5 text-[12px] gap-1.5 rounded-md",
  md: "h-9 px-3.5 text-[13px] gap-2 rounded-lg",
};

export interface ButtonProps extends ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: Variant;
  size?: Size;
  loading?: boolean;
}

export function Button({
  variant = "primary",
  size = "md",
  loading = false,
  disabled,
  className,
  children,
  ...rest
}: ButtonProps) {
  return (
    <button
      {...rest}
      disabled={disabled || loading}
      aria-busy={loading || undefined}
      className={cn(
        "inline-flex items-center justify-center font-medium transition-all",
        "disabled:cursor-not-allowed disabled:opacity-55",
        VARIANTS[variant],
        SIZES[size],
        className,
      )}
    >
      {loading && <Loader2 className="h-3.5 w-3.5 animate-spin" aria-hidden />}
      {children}
    </button>
  );
}
```

```ts
const BASE = import.meta.env.VITE_API_URL ?? "http://localhost:8000";

export class ApiError extends Error {
  constructor(
    readonly status: number,
    readonly title: string,
    readonly detail?: string,
  ) {
    super(detail ? `${title}: ${detail}` : title);
    this.name = "ApiError";
  }
}

export async function apiFetch<T = unknown>(path: string, init: RequestInit = {}): Promise<T> {
  const response = await fetch(`${BASE}${path}`, {
    ...init,
    credentials: "include",
    headers:
      init.body instanceof FormData
        ? init.headers
        : { "content-type": "application/json", ...(init.headers ?? {}) },
  });

  if (response.status === 204) return undefined as T;

  const contentType = response.headers.get("content-type") ?? "";
  const body = contentType.includes("json") ? await response.json().catch(() => null) : null;

  if (!response.ok) {
    throw new ApiError(
      response.status,
      body?.title ?? response.statusText ?? "Request failed",
      body?.detail,
    );
  }
  return body as T;
}
```

`events.ts`:

```ts
import type { AgentEvent } from "./types";

const BASE = import.meta.env.VITE_API_URL ?? "http://localhost:8000";

export interface RunHandlers {
  onEvent: (event: AgentEvent) => void;
  onDone?: (status: string) => void;
  onError?: (message: string) => void;
}

export function subscribeToRun(runId: string, handlers: RunHandlers): () => void {
  if (typeof EventSource === "undefined") return () => {};

  const source = new EventSource(`${BASE}/v1/runs/${runId}/events`, { withCredentials: true });
  const types = ["thinking", "tool_call", "tool_result", "message", "proposal", "error"] as const;

  for (const type of types) {
    source.addEventListener(type, (raw) => {
      try {
        handlers.onEvent(JSON.parse((raw as MessageEvent).data) as AgentEvent);
      } catch {
        /* a malformed frame is dropped rather than killing the stream */
      }
    });
  }

  source.addEventListener("done", (raw) => {
    let status = "succeeded";
    try {
      status = JSON.parse((raw as MessageEvent).data).status ?? status;
    } catch {
      /* keep the default */
    }
    handlers.onDone?.(status);
    source.close();
  });

  source.onerror = () => {
    handlers.onError?.("Connection to the agent stream was lost");
    source.close();
  };

  return () => source.close();
}
```
